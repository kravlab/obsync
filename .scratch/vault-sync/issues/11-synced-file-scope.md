# Synced file scope

Type: grilling
Status: open
Blocked by: 02

## Question

Which files does the plugin sync? Decide whether the vault configuration folder (`.obsidian/`: settings, plugins, themes, workspace layout) is synced in whole, in part or not at all, and how per-device files (e.g. workspace layout) are kept apart; the default ignore list and how the user edits it; that the plugin's own state never syncs; hidden files; and whether there is a file size ceiling. Depends on what the API can see, per [Obsidian platform constraints for sync](02-obsidian-platform-constraints.md).
